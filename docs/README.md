# Documentación

Por dónde empezar: `proyecto/mapa.md`. Para hacer algo: `funcionalidades/si-te-piden.md` (busca la frase del enunciado y te lleva a su receta).

| Carpeta | Qué hay |
|---|---|
| `proyecto/` | `mapa.md` (cómo encaja todo y árbol de ficheros), `paginas.md`, `modelos.md` y `analisis-profe.md` (qué hizo el profe y qué pistas da) |
| `backend/` | `api.md` (endpoints), `validaciones.md` y `mongodb.md` (Docker, `.env` y arranque) |
| `detalle/` | Apuntes largos por tema (listas y filtros, formularios, rutas y componentes), pensados para no salir de ellos |
| `funcionalidades/` | Recetas de lo que pueden pedir, con código para este proyecto: filtros, PDF, rutas con parámetro, props y emit, Pinia, entidades nuevas y más (empieza por su `README.md`) |
| `comprobar/` | `checklist.md` (al empezar y antes de entregar) y `errores-tipicos.md` (síntoma → causa → arreglo) |
| `guias/` | Qué ficheros tocar para cada tarea: pantalla, campo, filtro, validación, endpoint y aspecto |

Las guías son por ahora una lista de pasos y ficheros; se irán ampliando con ejemplos de código.
